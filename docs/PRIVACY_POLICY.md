# VYRO privacy policy

Last updated: 24 October 2026

## Data stored by VYRO

VYRO stores the profile and goals, meals, cached product lookups, workout plans and sessions, exercise sets, and body measurements in a local SQLite database. VYRO does not provide accounts or cloud sync. Analytics and advertising identifiers are not included.

## Network access

The app connects to Open Food Facts only when the user starts a barcode lookup and the product is not already cached. The request contains the EAN/UPC product identifier and technical request headers. Meal records, profile data, photos, workout videos, and movement landmarks are not sent to Open Food Facts or to an AI service.

## Camera and photo processing

Barcode scanning and optional squat analysis access the camera only after the user starts those screens. Food-photo classification runs on-device. Classification hypotheses are uncertain and do not determine ingredients, serving mass, calories, allergens, technique, or safety. Selected food photos are held temporarily in memory for review; the app does not retain or upload them. Squat video frames are processed in memory and are not saved.

## User controls

- Export prepares a JSON copy of local records for the user to copy and store.
- Import replaces current VYRO records with a valid export file pasted by the user.
- Delete all data clears VYRO profile, goals, product cache, nutrition records, workout records, and measurements on this installation.
- These controls cannot erase copies stored outside VYRO, including an export saved by the user.

## Operating system backups

Android app backup is disabled in the application manifest. On iOS, operating system and Apple account backup behavior is controlled by the device settings; users should review their iCloud/device backup choices.

## Data sources

Barcode data is attributed to Open Food Facts in the app. The bundled simple-food nutrient reference credits USDA FoodData Central; its data is public domain under CC0. Reference values describe named foods per 100 g and can vary with variety and preparation.
